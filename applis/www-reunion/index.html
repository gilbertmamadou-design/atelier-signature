Réunions

Pose le téléphone au milieu de la table, écran allumé. Le texte s'écrit pendant que les gens parlent ; touche « Décision », « Action »… au bon moment pour les retrouver dans le compte rendu.

La reconnaissance se fait sur le téléphone quand le français hors ligne est installé (Paramètres › Système › Langues › Reconnaissance vocale hors connexion). Sinon, Android passe par le service de Google.

00:00

Un toucher marque la dernière phrase entendue (et la suivante si quelqu'un parle encore). Touche une phrase pour changer son marquage.

Tout est fait sur le téléphone, rien n'est envoyé sur Internet. Le compte rendu est modifiable : tes changements sont gardés.

« Rédiger avec Claude » (facultatif) : la transcription et tes marquages partent dans ton appli Claude, sur ton compte, pour un compte rendu entièrement rédigé. Le texte passe alors par Internet : à éviter pour une réunion confidentielle.
