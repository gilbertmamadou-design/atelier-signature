Mes données

Où sont mes données ?

  • Chaque appli garde ses données (notes, rendez-vous, réglages…) dans le navigateur de cet ordinateur, sur ce compte Windows.
  • Le PC et le téléphone ne se synchronisent pas : ce qui est fait sur l'un n'apparaît pas sur l'autre. Edge et Chrome ne partagent pas non plus leurs données.
  • Effacer les données de navigation du site (ou désinstaller l'appli en cochant « effacer les données ») supprime tout : pense à exporter avant.

Exporter / importer

  • Sous chaque appli, « ⇅ Exporter / importer mes données » enregistre tout son contenu dans un fichier .json, à réimporter sur un autre PC ou un autre navigateur.
  • Ce fichier n'est pas chiffré (sauf le Coffre, dont le contenu reste chiffré) : garde-le en lieu sûr.
  • Pour passer du PC au téléphone, utilise la sauvegarde propre à l'appli quand elle existe (indiquée dans la fenêtre) : c'est le même fichier des deux côtés.

Relais réseau (facultatif)

Un navigateur ne peut lire un flux d'un autre site que si ce site l'autorise. Sur ordinateur, beaucoup de médias (Le Monde, Le Figaro, BBC, RFI…), le Journal officiel, PVGIS ou Project Gutenberg refusent : ces sources restent vides dans Actualités, Petits Pas, Solaire, Liseuse, Ondes et Écran. Les autres (franceinfo, Open-Meteo, la plupart des podcasts…) marchent sans rien faire.

Pour les retrouver, tu peux créer ton propre relais, gratuit, chez Cloudflare (mode d'emploi, rubrique « Relais réseau » du README) puis coller son adresse ici. Il ne sert qu'à tes applis, en lecture seule. Aucun relais public n'est utilisé.

Installer sur Windows

Microsoft Edge

  1. Ouvrir l'appli (tuile ci-dessus).
  2. Cliquer sur l'icône Installer à droite de la barre d'adresse (ou menu ⋯ › Applications › Installer cette application).
  3. Confirmer : l'appli a sa fenêtre, son icône dans le menu Démarrer et peut être épinglée à la barre des tâches.

Google Chrome

  1. Ouvrir l'appli (tuile ci-dessus).
  2. Cliquer sur l'icône Installer (écran avec une flèche) dans la barre d'adresse, ou menu ⋮ › Caster, enregistrer et partager › Installer la page en tant qu'appli.
  3. Confirmer. Désinstaller : clic droit sur l'icône dans le menu Démarrer › Désinstaller.

Ouvrir un fichier avec une appli

  • Une fois l'appli installée, clic droit sur un fichier dans l'Explorateur › Ouvrir avec : PDF › Lecteur PDF ou Atelier PDF ; .epub › Liseuse ; .ics › Agenda ; .vcf › Contacts ; .gpx › Sentiers ; musique › Mélodie ; vidéo › Écran ; photo › Galerie.
  • Au premier usage, Windows demande d'autoriser l'appli à ouvrir ce type de fichier.
  • On peut aussi glisser un fichier sur la fenêtre de l'appli, ou Ctrl+O.

Hors ligne et mises à jour

  • Après une première ouverture avec internet, chaque appli fonctionne sans connexion.
  • Quand une nouvelle version est publiée, un message « Nouvelle version disponible » propose de mettre à jour. Chaque appli affiche sa version (bouton ⓘ en bas à gauche, ou Fichier › À propos dans Présentation, Texte et Tableur) et propose « Rechercher une mise à jour ».
  • Ici, « Rechercher les mises à jour » vérifie toutes les applis déjà ouvertes sur cet ordinateur : chaque tuile indique « À jour » ou « Mise à jour prête ».
  • Les données restent dans le navigateur de cet ordinateur : elles ne passent pas d'Edge à Chrome (voir « Mes données »).
