# Atelier signature

Page publique d'émargement des réunions sécurité de l'appli **Atelier Tuyauterie**.

Le participant scanne le QR code de la réunion, écrit son nom, signe avec le doigt : la page affiche un QR code de retour que l'animateur scanne avec l'appli. **Aucune donnée n'est envoyée ni stockée en ligne** : tout passe par les QR codes.

Bibliothèque incluse : [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator) (MIT, © Kazuhiko Arase).
